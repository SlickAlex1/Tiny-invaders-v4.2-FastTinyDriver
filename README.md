Tiny Invaders 4.2 – FastTinyDriver Edition

This is a fork of the classic Tiny Invaders 4.2 game for the ATtiny85-based TinyJoypad console, updated to use the FastTinyDriver OLED display driver by Daniel C / Electro L.I.B.

Key Features:

    Uses FastTinyDriver by Daniel C / Electro L.I.B for direct SSD1306 I2C display (minimal, fast, and memory-efficient)
    Designed for TinyJoypad and similar ATtiny SSD1306 consoles at 16MHz
    Enables more available flash/RAM for enhancements and portability

Why this fork?
The original Tiny Invaders used the ssd1306xled library. This fork upgrades to the modern, optimized FastTinyDriver by Daniel C / Electro L.I.B, improving speed, memory footprint, and hardware compatibility.
